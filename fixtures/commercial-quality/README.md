# Commercial quality fixture matrix

These six fictional South African mid-market profiles exist only to exercise the binary quality
gates. They are not customer data and must never be rendered as customer-facing organisations.

The manifest records the profile, score/band and the failure mode each fixture is intended to
prove. F1 and F2 remain anchored to the persisted owner-review source records; F3-F6 are
specification fixtures for quality-gate coverage and are not used to alter scoring methodology.
